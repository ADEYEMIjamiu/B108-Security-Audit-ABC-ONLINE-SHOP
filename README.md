# Security Audit and Strategy Report for ABC Online Shop

## Overview
This project is an academic security audit conducted as part of the B108 Data Governance, Security and Ethics module at GISMA University of Applied Sciences.

## Objective
The project evaluates cybersecurity risks affecting an e-commerce platform and proposes a structured security strategy.

## Key Areas Covered
- Risk Assessment (NIST SP 800-30)
- Security Strategy (ISO 27001)
- Data Protection (GDPR)
- Risk Treatment Plan and Implementation Roadmap

## Files Included
- Final Report (PDF)
- Word Version
- Risk Matrix Diagram
